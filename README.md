# Sumber Sandang Store - E-Commerce Platform

Platform e-commerce fashion modern dengan dashboard admin, sistem keuangan, dan manajemen stok otomatis.

## 🎯 Fitur Utama

### Website Toko
- 🎨 Desain Pink Smooth (pink pastel, putih, abu-abu muda)
- 🛒 Katalog produk dengan filter
- 🔍 Pencarian real-time
- 🛍️ Keranjang belanja lengkap
- 💳 Checkout dengan berbagai metode pembayaran
- 📱 Responsive (mobile, tablet, desktop)

### Dashboard Admin
- 📦 Kelola produk & kategori
- 📊 Manajemen stok barang
- 👥 Kelola pelanggan & pesanan
- 💰 Dashboard keuangan real-time
- 📈 Grafik penjualan
- 🎁 Kelola promo & diskon

### Sinkronisasi Keuangan
- 📊 Pencatatan transaksi otomatis
- 💹 Laporan omzet, laba kotor, laba bersih
- 📉 Arus kas & rekonsiliasi pembayaran
- 📥 Sync ke Google Sheets otomatis
- 📥 Ekspor Excel & PDF
- 🔄 Riwayat sinkronisasi & status

## 🛠️ Teknologi

- Next.js 14 + React 18
- Tailwind CSS
- Node.js + Express
- PostgreSQL / MySQL
- Prisma ORM
- Google Sheets API
